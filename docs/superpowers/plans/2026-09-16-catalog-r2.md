# Catalog, Clients, Pricing and R2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar a Etapa 2 do backend: clientes, categorias, produtos, preço por cliente e mídia R2 multiempresa.

**Architecture:** Módulos Spring separados por domínio, JPA/Flyway com integridade de tenant no banco, DTOs sem `empresa_id`, autorização baseada em `TenantContext`, e storage abstraído por `ObjectStorage` com implementação R2/S3.

**Tech Stack:** Java 21, Spring Boot 3.5.16, Spring Data JPA, PostgreSQL 17, Flyway, Spring Security, AWS SDK v2 S3, Testcontainers.

**Spec:** `docs/superpowers/specs/2026-09-16-catalog-r2-design.md`

## Global Constraints
- `empresa_id` derivado do usuário autenticado.
- OWNER/ADMIN escrevem; VENDEDOR consulta apenas dados ativos e sem custo/margem.
- Soft delete para cliente/produto.
- TDD para comportamento novo.
- PostgreSQL/Flyway é a fonte de schema.
